# WallCal OAuth Site

Google OAuth verification用のWallCal公式サイト。

- 公開URL: https://wallcal.yutogemma.jp/
- プライバシーポリシー: https://wallcal.yutogemma.jp/privacy.html
- メインサポート: https://yuto-0906.github.io/WallCal/

公開サイトはGitHub Pagesで配信する。DNSの `wallcal.yutogemma.jp` は CNAME で `yuto-0906.github.io` を参照する。
Google Cloudのブランディングでは，上記の公開URLとプライバシーポリシーを登録し，承認済みドメインを `yutogemma.jp` とする。
Google Search Consoleのドメインプロパティで所有権を確認した後，ブランディングおよびデータアクセスの検証を進める。
旧ドメイン `keyboard-band.com` は使用しない。
